# Maximum Subset XOR

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-brightgreen)

## Problem

https://www.geeksforgeeks.org/problems/maximum-subset-xor/1

---

<p><span style="font-size: 18px;">Given an array <strong>arr[]</strong>, choose any subset of elements (possibly all elements) such that the XOR of the chosen elements is maximized.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input : </strong>arr[] = [2, 4, 5]<br><strong>Output: </strong>7<br><strong>Explanation: </strong>The subset {2, 5} has the maximum XOR value.</span></pre>
<pre><strong style="font-size: 18px;">Input : </strong><span style="font-size: 18px;">arr[] = [9, 8, 5]<br><strong>Output: </strong>13<strong><br>Explanation: </strong>The subset {8, 5} has the maximum XOR value.</span></pre>
